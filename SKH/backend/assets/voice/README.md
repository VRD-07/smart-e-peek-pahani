# Voice-call audio assets

## These files are placeholders. They are not Marathi speech.

Each `.wav` in this folder is a short tone pattern generated by
`scripts/generatePlaceholderVoiceAudio.js`. They exist so the voice rung of the
notification escalation ladder can be demonstrated end to end — Twilio really
fetches a real audio file and really plays it down a real phone call — without
shipping synthetic audio that pretends to be a Marathi recording.

If you are demonstrating this system, say that the voice channel plays a
pre-recorded message and that the recording itself has not been made yet.

| File | Notification type | What the farmer should hear |
| --- | --- | --- |
| `reminder-mr.wav` | `DEADLINE_REMINDER` | The filing deadline is close and nothing is on file for this season; send "Hi" on WhatsApp to file. |
| `calamity-relief-mr.wav` | `CALAMITY_RELIEF` | A calamity has been declared covering your registered field; your verified crop record may be used in the relief assessment; contact your talathi. Not an approval. |
| `submission-review-mr.wav` | `SUBMISSION_REVIEW` | Your crop record was received but has gone to an officer for review; it has not been rejected; do not file it again. |

The exact Marathi wording each file stands in for is stored as `script` next to
the filename in [`src/services/notifications/voiceMessages.js`](../../src/services/notifications/voiceMessages.js).
That is the text to record.

## Replacing a placeholder with a real recording

1. Record the `script` text for that notification type, read by a Marathi speaker.
2. Export as **8 kHz, mono, 16-bit PCM WAV** — the sample rate the phone network
   uses. A higher rate is not wrong, it just gets downsampled by Twilio.
3. Overwrite the file of the same name in this folder.

No code changes are needed. `buildVoiceTwiml()` resolves the URL from the filename,
so a dropped-in recording is picked up on the next call.

## Why `<Play>` and not `<Say>`

Twilio's text-to-speech has no Marathi voice. The nearest available is Hindi,
which mispronounces Marathi badly enough that a farmer could not reliably make out
a date or a Gat number — the two things the call exists to convey. A short human
recording is clearer and cheaper.

`buildVoiceTwiml()` does fall back to `<Say language="hi-IN">` when
`VOICE_AUDIO_BASE_URL` is unset, so a call still carries the message rather than
silence. That is a degraded stopgap, not the intended path.

## Serving these files

Twilio's media fetcher runs on the public internet, so `VOICE_AUDIO_BASE_URL`
cannot point at `localhost`. The backend serves this folder at `/assets/voice`;
for a local demo, expose it through a tunnel:

```bash
ngrok http 5000
```

then set `VOICE_AUDIO_BASE_URL=https://<your-subdomain>.ngrok-free.app/assets/voice`.

With the variable unset, the ladder still places the call and falls back to
`<Say>`; nothing breaks, it just sounds worse.
